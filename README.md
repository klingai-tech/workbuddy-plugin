# 可灵 AI WorkBuddy 连接器

本包通过可灵官方 OAuth MCP 服务，让 WorkBuddy 可以创建和查询图片、视频生成任务，并管理可复用主体、查询动作库。

本包只使用 `mcp.json` 中的端点：`https://klingai.com/mcp/plugin`。

## 功能

- 文生图、图生图
- 文生视频、图生视频
- 主体库（Element）的创建、查看、更新、删除与生成复用
- 动作库查询、通过库中动作或参考视频进行动作控制
- 本地素材两步上传（需当前 MCP 与宿主支持）
- 查询灵感值与任务状态
- 持续查询生成进度并返回结果

## 连接账号

在 WorkBuddy 中安装本包，点击“连接”，然后在浏览器完成可灵账号 OAuth 授权。授权和续期由 WorkBuddy 管理，不需要 API Key。

切换账号或区域时，先断开当前连接再安装和连接目标包。不要在对话中粘贴账号凭据、Token 或 Cookie。

## 使用

直接用自然语言描述想生成的图片或视频。每次只提交一个生成任务，并按服务允许的间隔持续查询，直到成功或失败。如果当前轮次先结束，会返回任务编号，之后可继续查询同一任务。

灵感值不足时，请充值后再试。完成后会返回可灵提供的主要图片、视频或结果链接。临时链接失效后，可以使用原任务编号重新查询。

也可以直接说“列出我的主体库”“把角色 Alice 的描述改为红发侦探”“查看已保存的动作”或“用这张主体图套用动作库里的挥手动作”。主体库和动作库查询只读取素材；套用主体或动作生成时，才提交生成任务。具体工具和模型以当前账号的实时能力为准。
