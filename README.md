# 可灵 AI WorkBuddy 连接器

本包通过可灵官方 OAuth MCP 服务，让 WorkBuddy 可以创建和查询图片、视频生成任务，并管理可复用主体、查询动作库。

本包只使用 `mcp.json` 中的端点：`https://klingai.com/mcp/plugin`。

## 功能

- 支持文生图和参考图编辑。未指定模型时，优先使用当前账号可用且符合需求的默认图片模型，具体规格以实时能力为准。
- 可灵 4.0 支持文生视频、首帧／尾帧／中间关键帧图生视频，以及混合图片、视频、音频和主体的全能参考。输出为 3–30 秒、720p，符合权限的账号可选 1080p。
- 可灵 4.0 Flash 支持文生视频、单张首帧图生视频，以及混合图片、视频和主体的全能参考。输出为 3–20 秒、720p。
- 两款视频模型的全能参考均支持智能分镜，可生成同步声音或保留参考视频原声，两种声音设置互斥。
- 主体库（Element）的创建、查看、更新、删除与生成复用
- 动作库查询、通过库中动作或参考视频进行动作控制
- 本地素材两步上传（需当前 MCP 与宿主支持）
- 查询灵感值与任务状态
- 持续查询生成进度并返回结果

## 连接账号

在 WorkBuddy 4.24.0 或更高版本中安装本包，点击“连接”，然后在浏览器完成可灵账号 OAuth 授权。授权和续期由 WorkBuddy 云端管理，不需要 API Key。

切换账号或区域时，先断开当前连接再安装和连接目标包。不要在对话中粘贴账号凭据、Token 或 Cookie。

## 使用

直接用自然语言描述想生成的图片或视频，也可以点名所需模型。未指定模型时，优先推荐当前账号可用且符合需求的 `omni_ref_video` 可灵 4.0 视频模型。图片默认推荐符合需求的可用图像模型。每个已授权的生成步骤只提交一次。宿主支持并已正常显示结果组件时，由组件刷新进度；否则按服务允许的间隔持续查询，直到成功或失败。如果当前轮次先结束，会返回任务编号，之后可继续查询同一任务。

灵感值不足时，可在可灵官网登录同一账号充值，再回到当前会话回复「继续刚才的任务」。WorkBuddy 会先核对原任务状态和余额。完成后会返回可灵提供的主要图片、视频或结果链接。临时链接失效后，可以使用原任务编号重新查询。

也可以直接说“列出我的主体库”“把角色 Alice 的描述改为红发侦探”“查看已保存的动作”或“用这张主体图套用动作库里的挥手动作”。主体库和动作库查询只读取素材；套用主体或动作生成时，才提交生成任务。具体工具和模型以当前账号的实时能力为准。
