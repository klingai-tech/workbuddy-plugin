# 可灵 AI WorkBuddy 连接器（国内版）

在 WorkBuddy 对话里用可灵 AI 生成图片和视频、查看生成进度，并复用主体库和动作库里的素材。

`main` 分支适用于在 **klingai.com** 登录的可灵账号，连接地址为 `https://klingai.com/mcp/plugin`。海外账号请使用 [`global` 分支](https://github.com/klingai-tech/workbuddy-plugin/tree/global)。

## 快速开始

1. **添加连接器**。打开 WorkBuddy 桌面端（4.24.0 或更高版本），在侧栏打开「连接器」（部分版本在「专家·技能·连接器」下），找到「可灵 AI」并点击添加。[WorkBuddy 连接器操作指南](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Connector)
2. **授权可灵账号**。点击「连接」，在浏览器登录国内站的可灵账号并完成授权，然后回到 WorkBuddy。WorkBuddy 会管理 OAuth 授权和续期，无需填写 API Key。
3. **确认连接**。从连接器卡片点击「去对话」，发送「用可灵 AI 查一下我还有多少灵感值」。看到余额后，就可以试试下面的生成示例。

完整的可灵接入方式见 [可灵 MCP 与 CLI 官方指南（国内站）](https://klingai.com/app/mcp/guide)。

## 查看结果与处理常见问题

- **生成还在进行**。在对话里的结果卡片查看进度。如果 WorkBuddy 返回了任务编号，可以在对话里说「用可灵 AI 查询任务 `<任务编号>` 的进度，完成后返回作品」。
- **作品链接过期**。用原任务编号重新查询，或登录同一个可灵账号查看生成历史。
- **灵感值不足**。在可灵官网登录同一账号充值，回到原对话说「继续刚才的任务」。如果任务已提交，WorkBuddy 会先查询原任务状态。
- **授权失败或需要换账号**。在 WorkBuddy 断开当前连接，然后用与连接器区域匹配的可灵账号重新授权。切换区域时使用对应版本的连接器。

## 功能

- [可灵图片 4.0](https://kling.ai/quickstart/kling-image-4-user-guide) 支持文生图和参考图编辑、原生 8K 及连续组图。未指定模型时，当前账号可用且符合需求就优先使用可灵图片 4.0，分辨率和单次张数以实时 MCP 能力为准。
- 可灵 4.0 支持文生视频、首帧／尾帧／中间关键帧图生视频，以及混合图片、视频、音频和主体的全能参考。输出为 3–30 秒、720p，符合权限的账号可选 1080p。
- 可灵 4.0 Flash 支持文生视频、单张首帧图生视频，以及混合图片、视频和主体的全能参考。输出为 3–20 秒、720p。
- 两款视频模型的全能参考均支持智能分镜，可生成同步声音或保留参考视频原声，两种声音设置互斥。
- 主体库（Element）的创建、查看、更新、删除与生成复用
- 动作库查询、通过库中动作或参考视频进行动作控制
- 本地素材两步上传（需当前 MCP 与宿主支持）
- 查询灵感值与任务状态
- 持续查询生成进度并返回结果
